# Sound Wave Generator

**Интерактивный инструмент для визуализации звуковых волн.**

## Функциональность
- Генерация звуковых волн с использованием Web Audio API.
- Контроль частоты и амплитуды с помощью ползунков.
- Адаптивный интерфейс для всех устройств (десктоп, планшет, мобильное).
- Темная и светлая темы.
- Доступность (WCAG, фокусировка, контраст).

## Установка
Просто откройте файл `index.html` в браузере.

## Скриншоты
- [Desktop](shots-desktop-settled.png)
- [Mobile](shots-mobile-settled.png)

## Настройка
1. Перемещайте ползунки для изменения частоты и амплитуды волны.
2. Используйте кнопки для экспорта результатов.

## Технические детали
- **Адаптивность:** Используются медиа-запросы для корректного отображения на всех устройствах.
- **Анимации:** Волна анимируется плавно с использованием CSS-анимаций.
- **Доступность:** Контраст текста и элементов управления улучшен для соответствия WCAG.
