# Sound Wave Generator

## Описание

Интерактивный генератор звуковых волн с поддержкой Web Audio API. Позволяет визуализировать звук в реальном времени с адаптивным интерфейсом и возможностью экспорта в SVG/PNG.

## Установка и использование

1. Откройте файл `index.html` в браузере.
2. Загрузите аудиофайл через кнопку "Загрузить аудио".
3. Настройте параметры волны (частота, амплитуда и т.д.).
4. Нажмите "Сгенерировать волну", чтобы визуализировать звук.

## Технические требования

- Браузеры: Chrome, Firefox, Safari, Edge (используется Web Audio API).
- Устройства: адаптивный дизайн для мобильных и десктопных устройств.
- Производительность: оптимизирован для слабых устройств (имитация 1.5 ГГц/2 ГБ ОЗУ).

## Экспорт волны

Волна может быть экспортирована в формат:
- **SVG**: сохраняет графическое представление волны.
- **PNG**: сохраняет текущее состояние волны.

## Настройка

Код доступен по [GitHub](https://github.com/your-repo/sound_wave_generator).

## Как протестировать

1. Имитируйте слабое устройство в Chrome DevTools (например, с флагом `--blink-settings=disable-hardware-acceleration`).
2. Проверьте плавность анимации и загрузку волны.

## Тесты

- Кросс-браузерная совместимость: Chrome, Firefox, Safari.
- Проверено на устройствах с разной производительностью.
