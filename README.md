# Sound Wave Generator

Простая утилита для генерации звуковых волн с настраиваемыми параметрами и прелоадером для улучшения UX.

## Функционал
- Генерация звуковых волн с поддержкой различных частот и амплитуд.
- Сохранение настроек в виде пресетов.
- Поддержка темной и светлой тем.
- Адаптивный дизайн для всех устройств.
- Прелоадер с анимацией для плавной загрузки.

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone <URL>
   ```

2. Откройте файл `index.html` в браузере через `file://`.

## Использование
- Изменяйте параметры с помощью слайдеров.
- Нажимайте кнопку «Generate» для создания звуковой волны.
- Сохраняйте настройки как пресеты.

## Тестирование
- Проверьте работу прелоадера на разных устройствах (десктоп, лаптоп, таблет, мобильные).
- Убедитесь, что прелоадер плавно исчезает после загрузки.

## Технические требования
- Современный браузер (Chrome, Firefox, Edge, Safari).
- Поддержка HTML5, CSS3, JavaScript (ES6).

## Настройка
- Для запуска в локальном режиме используйте:
  ```bash
  python -m http.server 8000
  ```
