# Sound Wave Generator

## Описание проекта
Проект для генерации и визуализации звуковых волн с использованием HTML5 Canvas и Web Audio API. Интерактивный интерфейс с адаптивным дизайном и поддержкой темного режима.

## Статус
**Завершённые задачи:**
- ✅ Адаптивный UI с темным режимом (`localStorage`).
- ✅ Плавная анимация волны (`requestAnimationFrame`) и загрузки (спиннер).
- ✅ Доступность: `aria-label`, `:focus-visible`, WCAG-контраст.
- ✅ Синхронизация анимации с параметрами слайдеров.
- ✅ Визуальный индикатор загрузки (спиннер) и плавные переходы.
- ✅ Адаптивность для всех устройств (десктоп, планшет, мобильное).

## Текущие улучшения
- Проверка UI-аудита и исправление мелких деталей.
- Оптимизация производительности и синхронизации.

## Технологии
- HTML5, CSS3 (с медиа-запросами), JavaScript (ES6+).
- Web Audio API для звуковых эффектов.
- Canvas для визуализации волн.
- LocalStorage для сохранения настроек темного режима.

## Доступность
- Поддержка `aria-label` для слайдеров и кнопок.
- `:focus-visible` для улучшения взаимодействия с клавиатурой.
- Соответствие WCAG для контраста и читаемости.
