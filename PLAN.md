# Sound Wave Generator

## Описание
Интерактивный инструмент для визуализации звуковых волн с возможностью экспорта в формате SVG и PNG.

## Актуальные задачи

### ✅ Завершено
1. **Адаптивность слайдеров**
   - Улучшена адаптивность слайдеров для частоты и амплитуды на всех устройствах.
   - Добавлены относительные единицы (`clamp`, `rem`) для корректного масштабирования.

2. **Анимации загрузки**
   - Исправлена анимация загрузки (вращающийся индикатор).

3. **Контраст иконок**
   - Иконки в кнопках теперь имеют высокий контраст с фоном (чёрный цвет на светлом фоне).
   - Добавлены SVG-иконки для кнопок с использованием `aria-label` для улучшения доступности.

4. **Улучшение доступности**
   - Добавлены атрибуты `aria-label` для кнопок с иконками.
   - Проведена проверка контраста для всех элементов.

### 🔧 В процессе
- Проверка экспорта волн в формате SVG/PNG на разных устройствах.
- Оптимизация производительности анимаций.

### 🚀 Следующие шаги
- Публикация на GitHub и тестирование пользователей.
- Дополнительные фичи (например, сохранение настроек, экспорт в другие форматы).

## Технические требования
- HTML5, CSS3, JavaScript (ES6+).
- Использование библиотеки Howler для звуковых эффектов.
- Адаптивный дизайн для всех устройств.
- Высокий контраст и доступность для всех пользователей.
