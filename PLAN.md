# Sound Wave Generator

## План проекта
### Введение
Интерактивный инструмент для визуализации звуковых волн с использованием Web Audio API.

### Основные фичи
- **Адаптивный интерфейс:** Подходит для всех устройств (десктоп, планшет, мобильные устройства).
- **Анимации:** Плавные анимации волны и индикатор загрузки.
- **Контроль параметров:** Частота и амплитуда волны регулируются ползунками.
- **Доступность:** Соответствие стандартам WCAG (контраст, фокусировка, темная/светлая темы).
- **Индикатор загрузки:** Визуальная обратная связь при генерации волны.
